# WeMake

An educational coffee-shop training game designed to teach real-world customer service, POS operation, and barista skills.

## Repository Structure

- [`docs/WM_Game_Design.md`](docs/WM_Game_Design.md) — Initial game design document (imported from Google Drive).
- [`prototypes/barista_prototype.html`](prototypes/barista_prototype.html) — Calm, accessible Barista Station HTML prototype.
- `reference/photos/` — Reference photos from the original Google Drive folder.
- `assets/` — Game art, audio, and UI assets (to be added).
