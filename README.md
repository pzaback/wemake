## Repository Structure

- [`docs/WM_Game_Design.md`](docs/WM_Game_Design.md) — Initial game design document (imported from Google Drive).
- `reference/photos/` — Reference photos from the original Google Drive folder.
- `assets/` — Game art, audio, and UI assets (to be added).
